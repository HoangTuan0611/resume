# Nguyen Hoang Tuan - Resume

Professional resume website with PDF download functionality built with Next.js

## 🚀 Features

- **Interactive Resume**: Clean, professional resume layout
- **PDF Download**: One-click PDF generation using html2pdf.js
- **Responsive Design**: Optimized for all devices
- **SEO Optimized**: Comprehensive meta tags and structured data
- **Social Media Ready**: Open Graph and Twitter Card support

## 🛠️ Development

```bash
# Install dependencies
yarn install

# Run development server
yarn dev

# Build for production
yarn build

# Start production server
yarn start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📱 PDF Download Feature


The resume includes a "Download PDF" button that:

- Clones the resume content
- Removes Tailwind CSS classes to avoid color compatibility issues
- Generates a high-quality PDF using html2pdf.js
- Downloads as `NguyenHoangTuan_Fullstack_Resume.pdf`

## 🌐 Deploy

Deploy to Vercel, Netlify, or any Next.js hosting platform.

Make sure to update:

- `metadataBase` URL in `app/layout.tsx`
- Sitemap URL in `app/sitemap.ts`
- Google Search Console verification code

## 📈 Performance

- **Framework**: Next.js 16 with Turbopack
- **Rendering**: Client-side rendering for interactive features
- **Image Optimization**: Cloudinary CDN
- **Styling**: Tailwind CSS with inline styles for PDF compatibility
